About This Project

An AI-powered translation system for Sourashtra (ꢱꣂꢬꢵꢰ꣄ꢜ꣄ꢬ), an endangered Indo-Aryan language spoken by ~500,000 people in Tamil Nadu, India. This website lets you look up English or Tamil words and see them in the native Sourashtra script (Unicode Saurashtra block U+A880–U+A8DF), rendered with the Noto Sans Saurashtra font.

📝 Sourashtra Script

The Saurashtra script is an abugida writing system derived from the Grantha script. It was encoded in Unicode 5.1 (2008) in the block U+A880–U+A8DF. This website uses the Noto Sans Saurashtra font by Google to render native script.
